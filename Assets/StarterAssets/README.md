# Starter Assets (Unity 6.6 native)

Asset Store の Starter Assets Third Person 1.1.7 は `.unitypackage` のため CLI では入れられない。

- `Scripts/StarterAssetsInputs.cs`
- `Scripts/ThirdPersonController.cs`
- `InputSystem/StarterAssets.inputactions`

公式パッケージを後から入れた場合は、このフォルダより公式 Prefab を優先してよい。
